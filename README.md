### What this build does

- JPG ↔ PDF / PNG ↔ JPG / TXT → PDF in the shipped Windows exe
- Zip-only distribution from pannki.com (no store)
- Founders window without a card

### What this build does not do

- OCR of scanned books
- 2 GB video
- public conversion API
- macOS / Linux packages
- EV-signed SmartScreen-quiet installer
